Momo Color Picker — installation guide (v1.1.0)
================================================================

Nix installation (ordinary installed Krita)
  1. Install Nix with flakes enabled, then clone this repository.
  2. Run once from the repository root: nix run .#install-plugin
     (the default `nix run .` is the same installer). It installs only
     installer-owned symlinks under $XDG_DATA_HOME/krita (default
     ~/.local/share/krita), and roots the Nix closure under
     $XDG_STATE_HOME/momo-color-picker/gcroots. It preserves settings and
     never changes PYTHONPATH or XDG_DATA_DIRS.
  3. Close any running Krita, then start your ordinary Krita from the desktop
     menu or with `krita`. Enable Momo Color Picker in Settings > Configure
     Krita > Python Plugin Manager and restart ordinary Krita.
     Installation does not auto-enable the plugin or alter configuration.
  4. Re-running the installer is safe and updates its own symlinks. Existing
     conflicting regular files/directories are refused, never overwritten;
     move them aside manually and retry. `nix run path:.#install-plugin` works
     from an untracked checkout.
  5. For development, run `nix develop`; this keeps the Qt6 test environment.

The Nix plugin package contains a private `_python_dependencies` symlink to
NumPy from the pinned nixpkgs `python3.withPackages`. This is ABI-compatible
with regular Krita only when Krita's Python comes from that same nixpkgs
revision; no PyQt binding is installed by this plugin.

Source archive
  MomoColorPicker-<version>-krita6-source.zip is platform-neutral source and
  contains no NumPy. It requires the host Krita Python to provide an
  ABI-compatible NumPy; the Nix package above supplies private NumPy instead.

Uninstall (Nix)
  Run `nix run .#install-plugin -- --uninstall`. It removes only the
  installer's exact user-data links and registered GC root; unrelated files
  and Krita settings are untouched. Removing the checkout does not uninstall
  the plugin; updating the package through the installer updates all links.

Windows status
  install.bat remains a source-file copier. NumPy discovery and Krita 6 on
  Windows are unverified; do not copy a NumPy build from another runtime.
